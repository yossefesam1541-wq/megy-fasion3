# خطة تفصيلية لبناء متجر إلكتروني متكامل (Medy Tech)

## 0. الهوية البصرية (Branding)
- **اسم المتجر/البراند:** Medy Tech
- **اللوجو:** تصميم احترافي (Vector - SVG) يشتغل بوضوح على الموبايل والديسكتوب، وله نسخة مصغرة (Favicon) ونسخة بخلفية شفافة لاستخدامه فوق الصور والبانرات
- **هوية الألوان والخطوط:** لازم تكون موحدة بين الموقع كله ولوحة تحكم الأدمن (ألوان أساسية + ألوان ثانوية + خط عربي احترافي يدعم RTL بشكل جيد)
- اللوجو يظهر في: الهيدر، الفوتر، صفحة تسجيل الدخول، الفواتير/الإيصالات، صفحة الأدمن

## 1. نظرة عامة على المشروع
متجر إلكتروني (E-commerce) يضم قسمين رئيسيين مختلفين تمامًا:
- **قسم الملابس** (منتجات متعددة المقاسات/الألوان)
- **قسم الموازين** (أجهزة/معدات وزن - منتجات تقنية غالبًا لها مواصفات مختلفة عن الملابس)

المشروع يحتاج: واجهة أمامية (Frontend) + خادم خلفي (Backend) + قاعدة بيانات + لوحة تحكم أدمن كاملة + نظام سلة مشتريات + نظام دفع عند الاستلام (Cash on Delivery).

## 2. خريطة الموقع (Site Map)

### أ. الواجهة العامة (Storefront)
1. **الصفحة الرئيسية**
   - بانر ترحيبي/عروض
   - بلوكين رئيسيين (كارت كبير) للتوجيه: "الملابس" و"الموازين"
   - قسم "الأكثر مبيعًا" أو "وصل حديثًا" (اختياري)
   - Footer فيه: تواصل معنا، سياسة الاستبدال، عن المتجر، السوشيال ميديا
   - سطر صغير أسفل الفوتر: "صُنع بواسطة Yossef Esam"

2. **صفحة قسم الملابس** (Landing Page كاملة خاصة بيها)
   - فلاتر: النوع (رجالي/حريمي/أطفال)، المقاس، اللون، السعر، الماركة
   - عرض شبكي (Grid) للمنتجات مع صورة/سعر/تقييم
   - ترتيب (الأحدث، الأقل سعرًا، الأعلى سعرًا)

3. **صفحة قسم الموازين** (Landing Page كاملة خاصة بيها)
   - فلاتر مختلفة تمامًا (النوع: ميزان مطبخ/ميزان جسم/ميزان صناعي، السعة بالكيلو، الدقة، البراند)
   - عرض المواصفات التقنية بشكل واضح لكل منتج

4. **صفحة تفاصيل المنتج (Product Details)**
   - صور متعددة + تكبير
   - اختيار مقاس/لون (للملابس) أو موديل/سعة (للموازين)
   - السعر، الكمية المتاحة، زر "أضف للسلة"، زر "اشترِ الآن"
   - تفاصيل ومواصفات + تقييمات العملاء (اختياري)
   - منتجات مشابهة

5. **سلة المشتريات (Cart)**
   - عرض المنتجات المختارة، تعديل الكمية، حذف منتج
   - حساب الإجمالي + الشحن + الخصومات (كوبون)

6. **صفحة إتمام الشراء (Checkout)**
   - بيانات العميل (اسم، عنوان، رقم تليفون)
   - طريقة الدفع: **الدفع عند الاستلام (COD)** فقط
   - تأكيد الطلب + صفحة "شكرًا لطلبك" مع رقم الطلب

7. **حساب المستخدم**
   - تسجيل دخول / إنشاء حساب / تسجيل دخول كضيف (Guest Checkout)
   - سجل الطلبات السابقة وتتبع حالة الطلب
   - العناوين المحفوظة

8. **صفحات إضافية**: من نحن، تواصل معنا، الأسئلة الشائعة، سياسة الاستبدال والاسترجاع، سياسة الخصوصية

9. **زر التواصل عبر واتساب**
   - زر عائم (Floating Button) ظاهر في كل صفحات الموقع لفتح محادثة واتساب مباشرة
   - رقم التواصل: **01154059667** (يُستخدم بصيغة دولية في الرابط: 201154059667+)
   - يظهر أيضًا في صفحة "تواصل معنا" وفي الفوتر بشكل واضح
   - يفضّل رسالة افتتاحية جاهزة تلقائيًا (مثال: "مرحبًا، عندي استفسار عن منتج في متجر Medy Tech")

### ب. لوحة تحكم الأدمن (Admin Dashboard)
1. **صفحة رئيسية (Overview/Dashboard)**
   - إحصائيات سريعة: عدد الطلبات، المبيعات اليومية/الشهرية، عدد الزوار، أكثر المنتجات مبيعًا، رسوم بيانية (Charts)

2. **إدارة المنتجات**
   - إضافة منتج جديد (اسم، وصف، صور، سعر، كمية، فئة فرعية، مواصفات مخصصة حسب القسم)
   - تعديل/حذف/إخفاء منتج
   - إدارة الفئات والأقسام الفرعية (مثلاً داخل الملابس: رجالي، حريمي؛ داخل الموازين: منزلي، صناعي)
   - إدارة المخزون (Stock) وتنبيه عند نفاد الكمية

3. **إدارة الطلبات**
   - عرض كل الطلبات (جديد، قيد التجهيز، تم الشحن، تم التسليم، ملغي)
   - تفاصيل كل طلب وتحديث حالته
   - متابعة تحصيل المبلغ نقدًا عند التسليم لكل طلب

4. **إدارة العملاء**
   - قائمة العملاء وبياناتهم وسجل مشترياتهم

5. **إدارة الشحن**
   - مناطق التوصيل وأسعار الشحن لكل منطقة
   - شركات الشحن (لو هيتم الربط مع شركة شحن)

6. **العروض والكوبونات**
   - إنشاء أكواد خصم (نسبة أو مبلغ ثابت)، تحديد تاريخ الصلاحية

7. **إعدادات عامة**
   - إدارة الأدمن ومستخدمي لوحة التحكم (صلاحيات متعددة)
   - إعدادات الموقع (شعار، بيانات تواصل)

## 3. نظام سلة المشتريات (تفصيل تقني)
- تخزين السلة في الـ Local Storage/Session للزائر غير المسجل، ثم ربطها بحساب المستخدم بعد تسجيل الدخول
- تحديث تلقائي للسعر الإجمالي عند تغيير الكمية
- التحقق من توفر الكمية في المخزون قبل إتمام الطلب

## 4. نظام الدفع
- **دفع عند الاستلام (COD) فقط:** لا يحتاج بوابة دفع إلكتروني ولا ربط خارجي
- عند إتمام الطلب يتم تسجيله مباشرة وإرساله لفريق التوصيل مع تحديد المبلغ المطلوب تحصيله
- الأدمن يقدر يحدّث حالة الطلب لـ "تم التحصيل" بعد التسليم

## 5. قاعدة البيانات (الجداول الأساسية المقترحة)
- Users (المستخدمين)
- Admins (الأدمن والصلاحيات)
- Categories (الأقسام الرئيسية: ملابس/موازين) + Subcategories
- Products (مع حقول مرنة للمواصفات المختلفة بين القسمين)
- ProductVariants (المقاسات/الألوان/الموديلات)
- Orders + OrderItems (تحتوي حالة التحصيل: لم يُحصَّل/تم التحصيل)
- Coupons
- ShippingZones
- Reviews (اختياري)

## 6. الـ Tech Stack المقترح (قابل للتغيير حسب الخبرة والتكلفة)
- **Frontend:** React / Next.js
- **Backend:** Node.js (Express/NestJS) أو Laravel أو Django
- **Database:** PostgreSQL أو MySQL
- **استضافة الصور:** Cloudinary أو AWS S3
- **الاستضافة العامة:** Vercel/Netlify للفرونت + VPS أو Render/Railway للباك إند

## 7. متطلبات الـ UX/UI
- تصميم Responsive بالكامل (موبايل أولاً)
- سرعة تحميل عالية وضغط الصور
- تجربة بحث وفلترة سلسة
- خطوات Checkout قليلة (لا تزيد عن 3 خطوات)
- دعم اللغة العربية (RTL) بشكل كامل واحترافي
- ألوان وهوية بصرية موحدة تناسب طبيعة كل قسم

## 8. الأمان
- تشفير كلمات المرور (Hashing)
- حماية من CSRF/SQL Injection/XSS
- HTTPS إجباري
- صلاحيات محددة لكل نوع مستخدم (Role-Based Access)

## 9. مراحل التنفيذ المقترحة
1. تصميم قاعدة البيانات والـ Wireframes
2. بناء الـ Backend والـ APIs
3. بناء الواجهة الأمامية (الصفحة الرئيسية + القسمين)
4. بناء لوحة تحكم الأدمن
5. الاختبار الشامل (Testing)
6. النشر (Deployment)

## 10. القرارات المبدئية المقترحة (قابلة للتعديل)
لحد ما تحدد اختيارات نهائية، الخطة مبنية على الافتراضات دي - عدّلها براحتك قبل ما تبعتها للـ AI:

| النقطة | الاقتراح المبدئي |
|---|---|
| Tech Stack | React / Next.js (Frontend) + Node.js (Backend) + PostgreSQL — اختيار مرن وحديث ومناسب لمعظم أدوات الـ AI البرمجية |
| الدفع | دفع عند الاستلام (Cash on Delivery) فقط، بدون بوابة دفع إلكتروني حاليًا |
| حجم المنتجات | تصميم قاعدة البيانات بحيث تستحمل من 500 لـ 2000 منتج بسهولة حتى لو البداية أقل، عشان التوسع لاحقًا من غير تعديل جذري |
| البراند | Medy Tech — مطلوب لوجو احترافي وهوية بصرية موحدة (تفاصيلها في القسم 0) |
| المنصة | موقع ويب فقط في المرحلة الحالية (بدون تطبيق موبايل)، لكن يُفضّل بناء الـ Backend بشكل جاهز للتوسع لتطبيق موبايل مستقبلاً لو احتجت |
| اللغة | الموقع بالعربي بشكل أساسي، مع بعض المصطلحات التقنية/الشائعة بالإنجليزي عند الحاجة (زي أسماء موديلات الموازين مثلاً) |
| التوصيل | لسه مش محدد (مندوبين داخليين أو شركة شحن) — يُفضّل تصميم قسم "إدارة الشحن" في الأدمن بشكل مرن يسمح بإضافة مناطق توصيل وأسعار يدويًا الآن، وربط شركة شحن خارجية لاحقًا لو لزم الأمر


و تصميم رائع داكن و فاتح و اضافه كل مميزات لتي تعرفها ان كانت مفيده الي الموقع و يجب ان يناسب جميع انواع و احجام الشاشات
